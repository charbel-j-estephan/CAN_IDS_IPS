How one dataset frame crosses the CAN bus

PC → ESP32 A → CAN bus → ESP32 B → PC. No model, no IDS. Press Play, or step through.

What the script checksIt compares every frame B reported with the list it sent: same ID, same length, same data bytes.
Flow controlESP32 A sends one byte A back to the PC every 64 frames, so the PC never gets more than 256 frames ahead.
Why 150 µs gapB’s 12 byte record takes about 130 µs on USB, slower than a full frame on the bus (about 110 µs).
